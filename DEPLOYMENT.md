## 📋 GitHub Secrets Required

For automated deployment to work, you need to configure the following secrets in your repository:

1. Go to **Settings** → **Secrets and variables** → **Actions**
2. Add the following repository secrets:

| Secret Name | Description | Example |
|-------------|-------------|---------|
| `VPS_HOST` | Your VPS hostname or IP | `vps.example.com` |
| `VPS_USER` | SSH username for deployment | `deploy` |
| `VPS_SSH_KEY` | Private SSH key for VPS access | Contents of your private key file |
